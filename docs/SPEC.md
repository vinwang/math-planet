# 算数星球：功能与实现说明

## 产品范围

算数星球是支持简体中文和英文的浏览器计算练习游戏。题目、SVG 角色、Canvas 粒子、WebGL 背景和 Web Audio 音频均在本机运行。部署只需静态文件，无服务端计算、账号或学习记录上传。

课程包含 58 个计算技能。年级安排和每项生成参数以 [curriculum.md](curriculum.md) 为准，不能据此宣称覆盖完整教材或获得教学效果认证。

## 语言

默认语言为简体中文。在首页设置中选择 `zh-CN` 或 `en`，偏好写入 `settings.language` 并重新载入页面。存档缺少语言字段、含不支持的语言值或无法读取时默认中文。语言保存失败时不刷新，恢复原语言选项并显示提示，以保留本次访问的未持久化进度。

英文显示名称为 Math Planet，伙伴名为 Nova。界面、引导、题目提示、技能、奖杯、收藏、日期和数字单位随语言显示。底层题目、输入数字与顺序、课程年级、技能及奖杯 ID 不随语言改变；原题和错题签名保持中文规范形式，仅在渲染时使用英文副本，避免切换语言产生重复或无法移除的错题。

英文仅为语言版本，未另行映射其他国家教材。语言切换不提供跨设备同步，仍遵循本机存档规则。

## 练习模式

| 模式 | 行为 |
| --- | --- |
| 适合我的练习 | 首次测评推荐一个练习起点，之后混合开放技能与已掌握技能复习 |
| 年级练习 | 基础题来自所选年级；加赛可逐步接触更高年级 |
| 技能练习 | 在技能树中选择开放技能，集中练习 |
| 错题复习 | 重做已保存的错题；整题首次答对才从错题列表移除 |
| 演示 | 自动展示一轮练习，不计入正常成长记录 |

每轮基础题可选 6、10、14 道，默认 10 道。错题复习最多取 10 道实际存在的错题；没有错题时不进入空练习。

首次测评保存 `progress.placementSkill` 作为建议起点，并在测评完成后开放该技能的练习入口。它不会直接标记该技能或前置技能为掌握，也不会直接授予星级。后续练习仍使用常规掌握规则。旧存档中已有的掌握状态保留。

## 输入、计时与得分

- 每次输入一个数字；竖式依次填写中间计算、商、余数等步骤。正确数字由星仔搬入对应格子。
- 答错可以重试，退格键只删除当前错误输入。同一步反复答错时，会逐步显示计算提示。
- 整题没有错误才计入首次答对。基础题全部完成后固定得到 100 分；首次正确率是整题首次答对数除以基础题数。
- 首次正确率达到 80% 且不是错题复习时，开放默认 90 秒加赛。加赛每题得分依次为 10、15、20……。
- 连对提高“星能”和演出强度，不改变基础得分。星能使用对数值记录，显示万、亿等中文单位。
- 左上角暂停按钮与 Esc 打开同一确认框。“继续练习”为初始焦点，Tab 在框内循环；暂停期间不接受答题输入，基础计时、加赛及连对期限暂停。
- 返回首页保留已完成题目的进度；基础结算前退出不会新增一次完赛记录。

## 技能成长

常规掌握门槛是最近 6 题至少 5 题首次答对。前置技能全部掌握后开放后续技能；测评建议起点有单独的练习入口。

掌握后继续按准确度、速度、间隔保持和综合表现获得最多 5 星。星级不会因为一次错误下降。21 天未温习的已掌握技能最多显示 3 个为待重温，首次答对可恢复状态。

记录每个技能近期 30 题用时、最近 60 天聚合以及最初 3 道原题，用于进步比较与时间胶囊。时间胶囊可在掌握且至少 30 天后重新展示原题。

## 持续练习与收藏

- 每日根据日期和已有进度选择 3 项任务，全部完成可获得补签锤，单日奖励只领取一次。
- 签到使用 7 日贴纸卡。补签锤最多持有 3 个，可按界面条件补最近 7 天内的缺席日以延续连续记录。
- 奖杯记录练习、技能、连对、成长和收藏等达成条件，获得后保留。完整目录以 `app/js/trophies.js` 为准。
- 隐藏条件包括 14 题全部首次答对、加赛至少完成 5 题且没有错误、周日完成练习等。
- 收藏包含背景、正确印记、粒子、音乐、装扮、颜色、观众和结束演出。物品由奖杯确定解锁；“自动”仅在已解锁项中选择。

## 视觉、声音与可访问性

新角色“星仔”使用五角星轮廓、单眼、轨道装饰和太空靴，参照 [star-pal.svg](star-pal.svg)。动态主角、观众、收藏图、粒子图和背景使用新的造型；模块中的历史标识不代表继续使用原角色形象。

音乐与音效由 Web Audio 合成，浏览器要求的用户交互后才启用声音。WebGL 不可用时退回 CSS 背景。界面使用系统中文字体，无远程字体请求。

动画强度可从 0% 调至 100%；未设置时尊重系统减少动态效果偏好。0% 会关闭主要位移、晃动、闪光和大量粒子，但不等于暂停所有渲染。

界面提供中文按钮名称、输入格标签、数字键盘和焦点标识，允许浏览器页面缩放。所有实机和屏幕阅读器组合仍需分别验证。

## 存档与兼容

存储键为 `dopa-drill:v1`，版本为 1，保留该键以兼容已有数据。应用读取旧日文错题和时间胶囊时只转换文案，并同步错题签名，保留数值、布局、答题步骤和学习记录。

| 数据 | 上限或规则 |
| --- | --- |
| 基础设置 | 题数限 6/10/14；音量和动画强度限 0–1；非法值使用默认值 |
| 完赛历史 | 最多 3000 条 |
| 错题 | 最多 40 道原题 |
| 技能去重 | 每个技能最近 24 个签名；生成时最多尝试 40 次避免重复 |
| 技能成长 | 最近 6 次正确性、30 次用时、60 天汇总和最初 3 道原题 |
| 其他 | 签到、任务、奖杯、收藏选择、补签记录等 |

旧存档中的年级完赛次数保留原有含义，不随新版课程映射重算。记录不会跨浏览器、设备或域名同步；保存被浏览器拒绝时，该次访问仍可练习，但记录不保证保留。

“全部重置”有两次确认，默认焦点均为取消。仅在第二次确认后删除以 `dopa-drill` 开头的键；无关存储键保留。

## 运行、测试与调试参数

启动与测试命令见根目录 [README.md](../README.md)。Node 单元测试覆盖生成、课程依赖、掌握、保存与迁移、计分、任务、奖杯和角色输出。浏览器测试覆盖手机核心流程、旧错题、非法参数和事件接线。

| URL 参数 | 行为 |
| --- | --- |
| `count=6/10/14` | 选择题数，其他值回退到 10 |
| `seed=<有限数值>` | 固定题目随机数；非法值忽略，视觉效果不保证全部固定 |
| `extra=<秒数>` | 允许大于 0 且不超过 3600 秒，非法值回退到 90 秒 |
| `skill=<存在的技能ID>` | 指定题型，未知 ID 忽略 |
| `demo` | 从适合我的练习入口启用历史固定题组；与设置中的自动演示不同 |
| `capture` | 收集音频事件，抑制现场声音与部分自动提示 |

调试参数不是无痕模式：`skill`、固定题组和 `capture` 对成长记录、完赛历史、错题和奖励的影响不同。需要隔离测试数据时，使用独立浏览器上下文。

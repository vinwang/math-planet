# 算数星球：计算内容与年级安排

本文记录当前应用提供的 58 个计算技能、生成范围和练习规则，供开发与课程核对使用。它只涵盖部分计算内容，不是完整的小学数学课程，也不能代替学校教学或正式测评。各地区、教材版本和教学进度可能不同，实际学习顺序以学校安排为准。

年级按中国大陆小学常见教学进度作应用内安排，尚未对某一教材版本逐页审校。课程标准按学段组织要求，本表中的具体年级不代表教育部逐项指定。实际使用前可结合学校教材核对。

为兼容既有存档，技能 ID 保持原样。ID 中的 `g1`、`g2` 等是历史标识，**不一定等于当前年级**；应以本表和代码中的 `grade` 为准。

## 年级概览

| 年级 | 技能数 | 主要内容 |
| --- | ---: | --- |
| 1年级 | 8 | 10以内及20以内加减、数的组成、简单两位数计算 |
| 2年级 | 13 | 两位数加减笔算、乘法口诀、表内除法和有余数除法 |
| 3年级 | 15 | 多位数加减、一位数乘除、两位数乘两位数、小数初步、简单同分母分数 |
| 4年级 | 6 | 三位数乘两位数、除数为两位数的除法、运算顺序、近似数、小数加减 |
| 5年级 | 10 | 小数乘除、因数倍数、约分、分数加减、简单方程 |
| 6年级 | 6 | 百分数、分数乘除、小数与分数、比 |

## 出题范围与限制

- 整数口算包含10的分解、一位数加减、三个数的加减、乘法口诀、表内除法及有余数除法。两位数加减口算也可能出现两个整十数；两位数除以一位数的口算被除数不一定是整十数。
- 整数笔算覆盖加减、乘法和除法。除法既可能整除，也可能有余数；竖式中的商和中间结果按步骤输入。
- 小数加减按一位或两位小数出题；小数乘除仅覆盖生成器当前支持的范围。小数除以小数目前只生成整数商，且通过横式输入。
- 分数包括同分母和异分母加减、带分数、约分及乘除。三年级同分母题目保持原分母，即使结果可以约分也按原分母输入。小数与分数混合题目前仅包含乘法。
- 混合运算目前包含加、减、乘和括号，不包含除法；近似数题保留到十、百或千位；百分数题目前只生成整数结果；求未知数题覆盖简单乘、加、减方程。
- 分数答案按“整数部分（若有）→分母→分子”输入；等价但与题目要求不同的分数形式不能直接替代。小数点和必要的竖式辅助数字自动显示。
- 图形、测量、统计、完整的应用题等不在当前题库范围内。题目按生成器条件随机产生，不代表教材中的全部题型。

## 测评、掌握与练习

第一次进入“适合我的练习”时，系统根据答题情况前后调整题目，并记下一个建议练习起点。本轮避免反复测试已首次答对的技能；连续答错时允许复测较低难度，避免把初学者推向更难的题。测评只提供初步建议，不把未练过的前置技能自动记为掌握，也不凭一次答题发放星级或掌握类奖杯。已保存的历史掌握记录保留。

测评完成后，建议起点可以直接练习，即使它的前置技能还未掌握。其他技能通常在全部前置技能掌握后开放。每道实际完成的题目仍正常计入该技能记录；达到最近6题至少5题首次答对的条件，才会正式掌握。已掌握的技能不会因一次答错而失去掌握状态。

学年练习从所选年级出题，不受技能树解锁状态限制；“错题复习”使用保存的题目。系统尽量避免近期和本轮重复，但候选题目有限时仍可能重复。具体生成参数以 `app/js/skills.js` 和 `app/js/problems.js` 为准。
